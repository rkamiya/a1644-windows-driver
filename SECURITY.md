# Security Policy / セキュリティポリシー

## Supported versions / サポート対象

Only the latest release is supported. / サポート対象は最新のリリースだけです。

## Reporting a vulnerability / 脆弱性の報告

Please **do not** open a public issue for security problems. Report them privately from the [Security](https://github.com/rkamiya/a1644-windows-driver/security) tab → **Report a vulnerability**.

セキュリティ上の問題は、公開の Issue に**書かないでください**。[Security](https://github.com/rkamiya/a1644-windows-driver/security) タブの **Report a vulnerability** から非公開で報告してください。

Please include / 報告に含めてほしい情報:

- Driver (Lightning / Bluetooth) and version / ドライバー（Lightning / Bluetooth）とバージョン
- Windows version and build / Windows のバージョンとビルド
- Steps to reproduce and the impact / 再現手順と影響

This is a personal project, so responses may take some time. / 個人のプロジェクトのため、返信に時間がかかることがあります。
